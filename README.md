# ♞ ChessGate

**Хүүхэд шатраар ялж байж л тоглоом, апп нээгддэг Windows програм.**

Хүүхэд хориглосон тоглоомоо нээхийн тулд эхлээд хиймэл оюунтай шатар тоглож ялах ёстой. Ялвал 60 минут нээгдэнэ. Хугацаа дуусмагц дахин автоматаар түгжигдэж, дараагийн нээлтэд илүү олон ялалт шаардагдана (1 → 2 → 3 → 4 ...). Шөнө дунд шаардлага дахин 1 ялалтаас эхэлнэ.

Ингэснээр эхний цаг хялбар, үргэлжлүүлэн суух тусам «үнэ» нь өсдөг — програм өөрөө өөрийгөө зогсоох механизмтай болно.

## Суулгах

1. `ChessGateSetup.exe` -г татаж аваад ажиллуулна
2. «Windows protected your PC» гэвэл → **More info** → **Run anyway**
3. Админ эрх асуусан цонхонд → **Yes**
4. **Install** дарна
5. Тохируулах туслах нээгдэнэ — эцэг эхийн нууц үг, хяналт тавих хүүхдийн account-ын нэр, нээлтийн минут, хүндрэлийн түвшинг оруулна
6. Компьютероо дахин асаагаад хүүхдийн account-аар нэвтэрнэ

### ⚠ Хамгийн чухал нөхцөл

**Хүүхэд заавал тусдаа, админ БУС (Standard) Windows account-тай байх ёстой.**

Админ эрхтэй хүн ямар ч түгжээг унтраадаг. Хүүхдийн account админ хэвээр байвал ChessGate ч, өөр ямар ч хяналтын програм тусалж чадахгүй.

## Шаардлага

- Windows 10 эсвэл Windows 11, 64 бит
- Суулгахад админ эрхтэй account
- Хүүхдэд тусдаа стандарт (админ бус) account
- Ойролцоогоор 300 MB сул зай
- Интернэт зөвхөн татахад — цаашид шаардахгүй

## Онцлог

- **Эцэг эхийн самбар** — нууц үгээр хамгаалагдсан; 15 / 30 / 60 / 120 минут шууд нээх, эсвэл «Одоо түгжих»
- **Тоглох цагийн хязгаар** — долоо хоногийн өдөр тус бүрээр зөвшөөрөгдөх интервал
- **Өдрийн дээд хугацаа** — хэдэн ялалт авсан ч өдрийн нийт хугацааг хязгаарлана
- **5 түвшний Stockfish AI** — шинэ сурагчаас клубын түвшин хүртэл; ферзьгүй / тэрэггүй тоглуулах хөнгөлөлт
- **Хоёр хамгаалалтын горим** — зөөлөн (жагсаалтад байгааг хаах) / хатуу (зөвшөөрснөөс бусдыг хаах)
- **Өөрөө сэргэдэг хамгаалалт** — систем эрхээр ажилладаг; ялалтыг үйлчилгээ тал шийддэг тул засаж хуурах боломжгүй
- **Хэд хэдэн хүүхэд** — account тус бүр тусдаа ялалт, тусдаа хугацаатай
- **Бүрэн офлайн** — бүртгэл, интернэт шаардахгүй; мэдээлэл гадагш илгээгддэггүй

## Устгах

Админ account-аас Тохиргоо → Апп → Суулгасан аппууд → ChessGate → **Uninstall**.
